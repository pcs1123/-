【新版說明】

這個版本已改成：
1. 網站主體就是一支 Y2K 翻蓋手機
2. 暗號輸入後，不會跳去新頁面
3. 內容會直接在手機螢幕內解鎖顯示
4. 手機設定成角色持有的手機

====================
你最常要改的地方
====================

請打開 index.html

【A】改手機主人名字 / 網站標題
搜尋：const PHONE_OWNER

你會看到：
const PHONE_OWNER = 'LUNA';
const SITE_TITLE = "LUNA'S PHONE";
const SITE_SUBTITLE = '輸入暗號後，直接在手機螢幕裡解鎖內容';

想改成自己的角色就直接改字。

--------------------

【B】改暗號與對應內容
搜尋：const phoneContents

你會看到像這樣：
'1234': {
  label: 'PROFILE',
  title: '角色基本設定',
  emoji: '✦',
  body: '名字：Luna\n身份：你角色持有的手機主人\n風格關鍵字：Y2K、甜酷、閃亮、收藏貼紙\n這裡可以改成你角色的基本資料、性格、背景設定。',
  tags: ['OWNER', 'PROFILE', 'Y2K']
},

左邊 '1234' 是暗號。
右邊 title / body / tags 是螢幕裡顯示的內容。

如果你想新增更多暗號，就照同樣格式再加一組。

--------------------

【C】操作方式
- 按手機按鍵可輸入
- 按 ABC / 123 可切換英文或數字輸入
- 按 UNLOCK 或中央 OK 可解鎖
- 按 BACK 可返回
- 按 HOME 可清空並回主畫面
