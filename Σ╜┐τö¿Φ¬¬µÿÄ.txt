kazami★彡 · V17 角色手機網站

這個資料夾已經包含完整網站、示範相簿圖片與搜尋圖示。

【先試玩】
1. 點兩下 index.html（建議使用 Chrome 或 Edge）
2. 點手機背殼翻開，輸入 1234，按中央圓形鍵
3. 點下方「相簿」圖示 → 進入分類 → 點照片 → 看大圖和說明 → 設為桌布
4. 返回時可以按手機上的「クリア」或螢幕左上角返回。

【只有你能更換搜尋欄左側圖示】
方法一：把自己的 GIF 改名為 owner-icon.gif，覆蓋 search-icons 資料夾裡同名圖片。
方法二：如果想用 PNG / JPG / WebP，可直接改 index.html 裡的 SEARCH_ICON_FILE，
例如改成 'search-icons/my-icon.png'，並上傳該圖片。
注意：訪客無法在網站裡更換這張圖；只有修改網站檔案並更新 GitHub 才會變更。

【相簿分類、照片與說明文字】
1. 打開 index.html，搜尋 const ALBUMS = [
2. title 是相簿或照片名稱；subtitle 是分類說明。
3. file 是圖片路徑；date 是日期；description 是照片下方介紹文字。
4. 把圖片放在 albums/<分類>/ 資料夾，改好對應的 file 路徑。
5. 若要新增照片，複製 photos 裡一整筆 { file: ..., title: ..., date: ..., description: ... }，
   然後換成自己的資料，記得和前一筆用逗號分隔。
6. 若要新增分類，複製整個 { id: ..., title: ..., subtitle: ..., photos: [...] } 區塊。
   id 不可重複，且請用英文數字命名。

【訪客會看到什麼】
相簿 → 相簿分類列表 → 照片縮圖 → 大圖＋文字＋「設為桌布」按鈕。
訪客只能看圖片、讀文字、換自己的桌布；不能上傳或修改照片和說明。
桌布選擇保存在訪客自己的瀏覽器，不會影響其他人。

【更新到 GitHub】
請把 index.html、search-icons、albums 等完整上傳到你的 Repository。
如果你之前已上傳舊版，可以把新版文件與圖片資料夾內容覆蓋，然後提交變更。
若 GitHub 上還留有以前的 wallpapers 資料夾，已不會被新版相簿使用，可以刪除。

【提醒】
密碼與搜尋暗號只是網站內的互動關卡，不是保密登入功能。
放在公開 GitHub Pages 的圖片與介紹，知道網址的人仍有機會直接查看。
